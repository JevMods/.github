## Hey, welcome to JevMods 👋

Here's where my Valheim mods live. Every one started same way: something in game kept annoying me, I got sick of it, so I fixed it. Fog that's everywhere and keeps me from finding dungeons in Mistlands, unreliable grappling hook, long unskippable intros... 😤

Mods are small on purpose. Each does one thing and has config file, so you can tune it or turn bits off. Logo is rune Jera (ᛃ), J sound, drawn so it also looks like code brackets 😎 Everything's open source, so poke around, borrow what's useful, tell me what's broken.

## 2,000 downloads, wow 🎉

All mods together just passed 2,000 downloads, and BetterFog alone hit 1,000 🥳 Huge thanks to everyone who installed something, rated it or opened issue. Seeing numbers go up for hobby project feels amazing 🙌

## Grab them 📦

Search mod name in [r2modman](https://thunderstore.io/c/valheim/p/ebkr/r2modman/) or Thunderstore app and hit install. BepInExPack_Valheim comes along automatically. You can also browse everything on [JevMods Thunderstore page](https://thunderstore.io/c/valheim/p/JevMods/).
